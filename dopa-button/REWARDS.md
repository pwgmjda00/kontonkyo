# ドパ・コレクターズ 運営ガイド（2026-10-31）

この機能は非換金の **無料デジタル報酬** です。実機確率の抽選や仮想玉／メダルの収支を賞金に交換する仕組みはありません。

## プレイヤー向け

- 🎟️ ステッカー: 初当たり1回、キラ2回、ホログラム5回、レジェンド10回。
- 🏅 称号: 当たり、機種収集、失敗、ハズレ、スコアなど17個。好きな獲得済み称号を装備。
- 📸 記念カード: 1080×1350 PNG。ブラウザ内で描画し、iPhoneの共有メニューまたはダウンロードで保存。個人情報の自動収集なし。
- 🏆 殿堂: GitHub Issuesで **本人同意して応募** → そのまま日替わり殿堂に表示。ブラウザがGitHub APIから新着を読み込むため承認は不要。
- 🎬 演出案: 20機種のステッカーを解放したユーザーが絵文字演出テーマを応募可能。採用は運営次第。

プロフィールやコレクションはブラウザの localStorage に保存されます。Safariの閲覧データ削除やプライベートモードではデータが消えることがあります。別の端末への同期は未実装です。プレイの正当性をサーバー検証していないため、収集数・記念カード・反射スコアは **賞金や競技順位の根拠にしてはいけません**。

## 殿堂の即時公開・日次保存

1. プレイヤーはゲーム内の「🏆 応募してすぐ殿堂に載る」からGitHub Issuesの入力フォームに進みます。GitHubアカウントが必要で、**掲載への同意**が必須です。本名・住所・電話番号・決済情報を求める項目はありません。
2. フォームから公開Issueを作成すると、ゲームの殿堂タブがGitHub公開APIを直接読みます。ゲームに戻り「🔄 最新に更新」を押せば、承認作業やサイト再デプロイなしで表示できます。GitHub API側の反映に数秒からの遅延がある場合があります。
3. 公開Issueのタイトル、本人同意、入力欄、URL、公開状態を確認します。長い投稿はニックネーム16文字、コメント60文字などに切り詰めます。文字列はReactのテキストとして描画し、HTMLとして解釈しません。
4. 荒らし・不適切な投稿はGitHub側でIssueを閉じるか、Issueに **dopa-hall-hide** ラベルを付けると次の読み込み時に非表示になります。事前承認は不要です。
5. GitHub APIに障害や閲覧制限がある場合は、毎日09:12 JSTに作成する公開スナップショットをフォールバック表示します。通常時はAPIを優先します。
6. GitHub Actions の **Daily Dopa Community Hall** が毎日09:12 JSTに公開Issueを読み込み、data/hall_of_fame.json と dopa-button/play を一括更新します。GitHub側のスケジュール処理により予定時刻より遅れることがあります。
7. 直近30日、1日20名までを表示し、同じ日付・同じ公開ニックネームの重複は避けます。投稿は掲載のためのプロフィール紹介であり、勝敗・獲得数の公式ランキングではありません。

**注意：** GitHub Issuesは公開されるため、投稿内容はゲーム外からも閲覧可能です。掲載が望ましくない投稿は運営側で削除・クローズできます。承認が不要な代わりに、運営が公開Issueを適宜確認することを推奨します。

## 演出テーマの採用

dopa-theme.yml で応募された絵文字・台詞を読み、採用する案は運営が審査し、コードに取り込みます。20機種達成はクライアント表示であり、運営側で厳密な不正検証はできません。著作権や肖像権を侵害する画像を無断使用しないでください。

## 実装

- src/machineRewards.ts: 過去の獲得IDを移行する称号・ステッカー管理
- src/machineCard.ts: 機種画像のCanvasローカル生成、共有とPNGダウンロード
- src/RewardsHub.tsx, src/rewards.css: iPhoneのPUSHを優先する折りたたみUI
- src/MachineCelebration.tsx: 初獲得の絵文字演出とその場でのカード保存
- tools/publish_hall.py: 同意済み公開Issueの日次バックアップ
- tools/test_publish_hall.py: 同意・非表示・URL判定の回帰テスト
- .github/workflows/dopa-hall-weekly.yml: 毎朝9:12 JSTの公開スケジュール

- src/liveHall.ts, src/liveHall.test.ts: GitHubの公開APIから即時取得、表示制限・安全性チェック
