# ドパボタン

**押すな。でも押せ。** 中央のPUSHひとつで遊ぶ反射ゲーム。

- 公開先：<https://pwgmjda00.github.io/kontonkyo/dopa-button/play/>
- ソース：<https://github.com/pwgmjda00/kontonkyo/tree/main/dopa-button>
- 既存ゲームを変更せず、新しい `dopa-button/` に独立して保存しています。

## 起動・検証

Node.js 22以上、Python 3。

```sh
npm ci
npm run validate:data
npm test
npm run build
npm run dev
```

本番ビルドのブラウザー検証：

```sh
npm run test:browser
```

ブラウザーテストはPlaywrightとChromiumを使用します。このクラウド環境では導入済み。別環境ではPlaywrightとブラウザーを準備してください。実機Safariの検証とは区別します。

## 変わらないルール

開始と再挑戦はPUSH。「押せ！」は時間内に1回、「押すな！」は一切押さずに待つ。成功すると反射スコアが1増え、自動で次へ進みます。誤操作・押し忘れで即終了。指示は公平な暗号乱数で50:50です。時間は1.5秒から短縮し、下限0.7秒。ラウンドをまたぐタッチやキーの持越しは入力トークンで破棄します。

タブ非表示・図鑑を開くと一時停止。復帰はカウントダウン経由。BONUS中はゲーム時間を停止し、終了・スキップ後にもカウントダウンします。

## 3モード

| モード | 成功後の抽選 | 最高記録 |
| --- | --- | --- |
| 通常 | 数学1026条件をそれぞれ独立抽選。独立1/99で演出判定 | ドパと共有 |
| ドパ | 通常と同じ抽選。虹・粒子・音を強化 | 通常と共有 |
| ゲーミングドパ | 排他的な超激熱5%・激熱20%・通常75%のカジュアル演出 | 専用 |

モード変更は開始前とゲームオーバー時だけ。ゲーミングドパでは数学イベントの実当選記録を増やしません。全モード初期ミュート、音声切替・光刺激軽減・システムのモーション軽減設定・演出スキップに対応します。

## 確率データと演出

添付の `data/probability_events_1026.json` を変更せず採用。18実験族×57条件＝1026件であり、独立した学術発見1026件や実機のスペックではありません。添付の `tools/validate_data.py` で1026件・18族・642件のBONUS対象を確認しました。数学式の独立再計算でも分数が一致しています。

分子・分母は文字列からBigIntへ変換し、`crypto.getRandomValues` と棄却サンプリングで偏りなく各イベントを独立抽選します。143桁の分母もNumberへ丸めません。1026件の処理はWeb Workerで実行し、UIを塞ぎません。

BONUS対象は厳密に `numerator * 257 <= denominator`。成功ごとに別途1/99を抽選します。演出判定成立時、BONUS対象の実当選があれば最も希少なものを1つ表示。対象の実当選がなければ「確率シアター／演出のみ」と表示します。シアター・プレビューを実当選の記録に混ぜません。演出OFFや演出判定の非当選でも、全実当選を記録します。99回目の保証はありません。

フリーズ・確率崩壊・宇宙終焉の3演出があります。宇宙終焉は演出テーマで、架空の宇宙発生確率は追加していません。

## 記録・図鑑

localStorageへモード別記録、プレイ・成功・待機成功、条件別当選数、最も希少な当選、直近100件の履歴を保存します。履歴を打ち切っても累計・図鑑は残ります。図鑑は名前・条件・実験族で検索し、正確な有理数による希少度で並べ替えます。100回独立試行の参考値は `-expm1(100 * log1p(-p))` の近似表示であり、抽選には使いません。

共有はWeb Share API、非対応時はコピー。スコア・モード・URL・`#ドパボタン` を含みます。

## 実機データ

登録0件。公式メーカーの一次資料を確認できていないため、数値や出典を捏造していません。拡張用 `MachineReference` スキーマには機種名・メーカー・型式・導入年月・条件付き有理数・出典・確認日・近似値フラグがあります。実機のRUSH等の条件付き確率を数学抽選には混ぜません。
