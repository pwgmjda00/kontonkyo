# JOKER 77: 実装と互換性

最終更新: 2026-11-07

## 共通エンジン

- `engine/jokers.js` は11系統×7種、計77種の定義を持つ。日替わり候補7枚は日付文字列をシードにした決定的抽選。
- `fifty-two-joker-equip-YYYY-MM-DD` に端末の当日装備1枚を保存。前日の装備は当日有効にならない。アカウント同期はない。
- `applyScore(joker,base,ctx)` は得点補正77種（`ctx.round`, `ctx.totalRounds`, `ctx.final`, `ctx.win`, `ctx.streak`, `ctx.behind`, `ctx.tie` 等）。条件が意味を持たないゲームでは既定値にする。
- `battlePower(joker,player,enemy,ctx)` はWARの戦闘値補正77種。
- `targetPower(joker,player,dealer,limit,ctx)` はブラックジャック／限界突破向けの11系統別補正。
- `engine/joker-score-mode.js` はスコア型ゲームへの接続部。通常とJOKERを明示的に切り替え、装備中のジョーカーを**局開始時に固定**する。終了時JOKER得点は別枠で計算し、途中でモードを変更した場合は確認してから対局をリセットする。
- `engine/joker-actions.js` は副作用なしの共通操作API。`peek`（先のカードを透視）、`suitCounts`（山札枚数）、`highLowHint` / `countdownHint` / `lineHint`（確率・1手ヒント）、`canRescue`（1回救済）、`effectiveCard`（カード数字の上げ下げ）を定義する。その他の能力は変更せず、ゲーム別に明示的にサポートする。
- JOKER対局内の数字変異は通常自己ベストと分離する。カウントダウンの通常最高得点はJOKERモード中に上書きしない。

## テスト

- `joker-test.html`：77種のスコア・戦闘能力値、日替わりの再現性、総ターン数による最終局面の補正などを確認するセルフテスト。
- `tests/gameplay-smoke.cjs`：装備・保存と、追加4作品のJOKERモード切替、最後までプレイした得点比較、Undo、リロード時のモード記録を自動実行。
- `tests/joker-actions.cjs`：アクション能力8種類の対応表、数字変異、救済1回制限、山札枚数、ヒント計算、通常スコア分離をNodeで回帰検証。静的スモークワークフローから毎回実行。
- `tests/gameplay-smoke.cjs`：固定日付でJOKERを装備し、HIGH / LOW・カウントダウン・フォールトラインにおける透視・ヒント・救済・数字変異をPlaywrightで確認。
- 共通のゲーム操作テストと全ページ起動テストは既存CIを維持。

## 次の統合方針

1. **処理順序の統一**：カード行動の判定 → 基本得点 → JOKER補正 → 結果表示。補正の種類と計算結果を各ゲームで正確に表示する。
2. **効果の系統別API**：情報公開、山札・カード変更、1手救済、戦闘値補正、スコア補正を明示的に区別する。スコア補正だけで「全能力の操作実装」とは数えない。
3. **ゲーム別対応表**：各ゲームのクリア条件・手数・勝敗・スコア・セーブ方式に合わせて統合する。ソリティア系では不可能な効果に無理な代替処理を割り当てない。
4. **対戦公平性とセーブ**：通常モードの記録を変更せず、JOKER装備の日付、効果、確定済み補正を必要に応じて一局ごとに固定して保存する。
5. **統合テスト**：本来のルールを維持したまま、全77種の効果条件、勝敗・Undo・復元、UIと得点の一致を網羅する。

## 配置・ソリティア系（phase 1）

- 共通ブリッジ `engine/joker-layout-mode.js` を追加。通常/JOKER切替、対局開始時の装備固定、得点を分離。各作品のカード操作をブリッジから呼び出し、効果がない場合は明示する。
- クロンダイク：山札を引く前の先読み、山札スートの可視化、合法な推奨手の常時ハイライト。フリーセル：合法な推奨手の常時ハイライト。既存の合法手・カードの移動ルールは変えない。
- ピラミッド：山札情報・推奨ペアのハイライト・カード数字+1/-1を13判定とUIの双方に適用。数字変異はJOKER対局のみ。救済3種は手詰まりのとき公開済みの場札を1枚だけ除去できる。
- 3作品とも通常勝利とJOKER勝利を別のlocalStorageキーに保存。JOKER時の勝利は通常実績を増やさない。UndoはJOKER勝利数と救済使用の状態も戻す。
- 対応カード操作はゲームごとに限定。該当しないJOKERでも終了時の得点補正は実行する。全77種に各ゲーム固有のカード操作がある、という表示はしない。
- `tests/joker-layout.cjs` はモバイルChromiumで初期化・装備・能力表示・操作・モード切替を回帰確認する。

## 配置・ソリティア系（phase 2）

- スパイダーは単一スート104枚構成を維持し、`peekNext` は次の10列分の配札順を事前表示。`revealCount` は♠の山札残数を表示。`hintChance` は既存の合法手から移動元・移動先を緑枠で提案。元の配札禁止条件や13枚回収ルールは変更しない。
- ユーコンの `peekNext` は7列それぞれ、直近で裏返り得る裏向きカードを可視化。`revealCount` は裏向き21枚を対象にスート別残数を表示。`hintChance` は既存の合法手を提案。
- エイト・オフの `hintChance` は空きセルと空列を加味した既存合法手を提案。移動可能枚数・同スートの積み方・組札ルールは不変。
- 3作品のJOKER勝利記録は通常勝利と分離。途中のモード変更は確認して再配札し、Undoで勝利数を復元する。
- 共通 `joker-layout-mode.js` にゲーム専用配札プレビュー、単一スート表示、未公開カード種別のラベル付けを追加。
- モバイル専用テストにスパイダーの「予告10枚と実配札の一致」、Undo、情報可視化、3作品のモード切替・推奨手を追加。スコア能力以外の77種すべてのアクション発動を主張しない。

## 配置・ソリティア系（phase 3）

- スコーピオン：山札の残り3枚は列1→列3へ配るため、J22でその3枚の順を表示。J24は未公開山札だけのスート別枚数を表示。J26は現在の合法な束移動を強調する。完成列は固定したままで、Undo時も情報と表示が復元される。
- ペンギン：J26はK→Aの循環・基準カード・7つのセルを含む既存の合法手を推奨する。カード数字や基準値は変更しない。
- キャンフィールド：J22は次にめくる最大3枚を公開順に表示。J24は山札内訳。J26は予備札・捨て札・4列・組札の合法手を提案する。3枚めくりや再配札、予備札自動補充は変えない。
- 3作品とも通常勝利とJOKER勝利を別キーで保存し、モード変更時は局をリセットする。Undo時に勝利数の記録を復元する。
- `tests/joker-layout.cjs` に3作品のモバイル操作・配札予告と実際の一致・スート集計・モード分離を追加。

## 数字連鎖系（phase 4）

- ゴルフ：J22は次の1枚の山札を先読み、J24は山札16枚からのスート内訳を更新。J26は次に打てる場札が多く残る合法手を水色で強調。J50/J51は表示と判定で公開札・基準カードの数字を同じルールで±1変異させる（A/Kで固定）。A↔Kは接続しない元のルールを保持。
- トライピークス：J22/J24は山札23枚の透視・内訳。J26は次に開くカードを考慮した推奨を水色で表示。J50/J51の数字変異は表示・除去判定の双方に適用。通常の3峰構造、連続除去、Undoは不変。
- ブラックホール：もとから吸収可能な札は緑枠なので、J26は吸収後の合法選択肢が多い列を金枠で推奨。A↔K循環と17列×3枚は不変。非対応のJ22/J24や数字変異は終了時スコア補正のみ。
- 共通レイアウトブリッジの`rescueRemoval`を独立指定に変更。数字変異があるだけで救済操作まで「できる」と表示しない。既存ピラミッドのJ64などの1回救済は維持。
- 3作品は通常勝利とJOKER勝利を別々に保存。終了時のスコア補正、Undo時の勝利復元、モード変更による局リセットを追加。

## ペア消去型（phase 5）

- イレブンズ：合計11の2枚、J/Q/Kの3枚という元の除去条件を保持。J22は山札先頭から最大3枚を予告し、J24は補充前の残りスート構成を表示。J26は候補を除去・補充した後の盤面をシミュレーションし、次に合法な組が多い候補を水色で推奨。2枚・3枚とも評価する。
- フォーティーン・アウト：合計14の2枚ペアのルールは不変。J26は13列の2枚除去で現れる次のトップカードまで考えて推奨。山札がない作品なのでJ22/J24のカード情報効果は発動せず、終了時の得点補正のみ。
- モンテカルロ：J22とJ24は先頭からの補充札と残数を表示。J26はペア除去後、詰め・補充した場合の5×5盤面まで予測してペア候補を推奨する。8方向隣接と詰め直し操作は従来どおり。
- ネスター：8列と4枚の予備札の中から同ランク2枚を消す既存の合法手を評価し、下の札が公開された後の候補数で推奨。予備札の使い方と重複なしの配札ルールは変更しない。
- 4作品ともJOKERの得点と勝利数を通常記録から分離し、UndoでJOKER勝利も適切に復元。モード変更後は新しい対局として配り直す。
- 数字変異J50/J51は、ペア消去の成立条件と52枚完遂可能性を崩す可能性があるため操作能力としては**未対応**。終了時得点補正のみ適用し、使えると偽って表示しない。
