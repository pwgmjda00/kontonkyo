# FIFTY-TWO / JOKER 77 開発規約

対象は `fifty-two-preview/` のみ。他作品・既存セーブ・ゲームルール・機能を保護する。UX最優先。合理的な改善は実装し、テストを弱めて成功扱いにしない。

## 作業開始と中断への備え（すべての後続AIへ継承）
- 作業開始時にこのファイル、`docs/HANDOFF.md`、`docs/achievement-coverage.md`、git status / log を読み、最新コードとCIを実際に確認する。会話や古い台帳を最新状態の代わりにしない。
- 各まとまった実装・テスト・失敗・コミットの直後に `docs/HANDOFF.md` と `docs/RESUME_PROMPT.txt` を更新する。引き継ぎは開発工程の一部。終了時やトークン制限直前まで後回しにしない。
- 台帳には確定仕様、基点と最新の確認済みHEAD、作業ブランチ/PR、変更ファイル、実行コマンドと結果、未検証事項、エラーの要点、次の具体的作業、公開確認を短く残す。
- 中断前は可能な範囲で台帳もコミット。未コミット差分の場所と理由を記載。認証情報・トークン・個人情報は保存しない。
- 「やろう」「続けて」は台帳の次の未完了項目を実装する指示。調査報告だけで終わらない。次のCodex、ChatGPT、その他AIにもこの規約を継承する。

## 確定仕様
- 独立72作品とindex内5作品、合計77。図鑑・テストページは除外。
- 毎日、未所持優先の3択（残り3未満なら残数）から1枚。同日1枚、時計を戻しても重複不可。
- JOKER77種は永久所持。装備・解除可能、効果の適用タイミングを明示。獲得で既存装備を勝手に変更しない。
- 各作品の最高実績を初達成すると未所持から1枚。既達成記録も対象。作品ごとに1回、通常/JOKER実績からの重複不可。
- 勝利確定箇所の明示フックを優先。訪問・操作・敗北は勝利扱いしない。記録形式・到達条件はcoverage表に明記。

## 検証
既存 `.github/workflows/fifty-two-*.yml` のコマンドを実行。新しい実績・状態テストも実行。成功を未確認のまま記載しない。公開はPages URLの実際の応答と変更反映まで確認する。
