# 輪廻工房 v85

「攻略で壁を突破 → 固定狩りで準備 → 転生で次の成長を速める」を目的とする20機能。基本の装備比較・狩り選択・敗北分析・転生履歴は無料。便利な追加自動化は一度買えば永久解放、能力強化は繰り返し購入できます。本番へのマージ・公開はこの作業に含みません。

## 転生ポイント RP

無窮の通常攻略で今回の最高撃破階層を記録します。Lv25以上かつ攻略6階以上を撃破して転生すると、次を付与します。

```
floor(sqrt(Lv - 24) + 2 * sqrt(今回の最高撃破階層 - 5))
```

例：Lv25・6階で3RP、Lv39・25階で12RP、Lv100・100階で28RP、Lv500・1000階で84RP。狩り・巨大箱ボス・前世対戦はこの階層記録を増やしません。ゆめかわの旅もRPの直接獲得条件にはなりません。取得済みの過去の転生回数をポイントへ換算する処理はありません。既存セーブの今世の攻略勝利数は引き継ぎます。

転生確認がキャンセルされたら付与なし。従来の確認・復旧スナップショットを維持し、転生実行時に一度だけ付与。転生画面とHUDに所持RP・見込みRPを表示します。ショップ・ノードの購入は所持RPを確認して一回の取引で差し引き、買い切り機能を二重購入できません。

繰り返し購入価格は `ceil(初回価格 × (1+現在Lv)^1.5)`。初回はエンジン1RP・戦闘1RP・出発セット2RP。5Lv単位の成長を感じながら、価格は段階的に増加します。建物効果・読書・旧戦利品・既存秘蔵・超越装備とは独立して合成し、生産だけで攻撃力が増える式には戻しません。

家宝は通常装備の元の効果に加え、分類順に生産/回復/HP/生産/回復のいずれかを伸ばします。画面に現在の対象能力と実際の補正を表示。家宝の継承回数は家宝枠に蓄積し、指定装備を変更しても保持します。

箱ボスの専用戦利品10種は生産・攻撃・HP・回復を順に強化。1種類の初回は＋5%、重複は `5 × (1+0.2log2(個数))%`。星座は生産＋10%、攻撃＋15%、HP＋15%、回復＋15%、冠は全能力＋10%、箱の星だけは工場箱生産＋10%。家宝・専用戦利品・影の証・星座は能力ごとに加算合成してから、エンジン・戦闘の基礎倍率へ適用します。

通常1,000箱の基礎期待数は、装備・カード合計で虚構0.8個・界外0.08個・不可思議0.008個（天井除外）。合体は通常装備・低等級・超越抽選・各種天井を手放し、種類を選んで上級品の比率を高める取引です。

## 攻略と狩りの分離

攻略は従来v83曲線に、30階以降 `P=1+0.003×(階層−30)` のHP補正・`sqrt(P)` の攻撃補正を追加。ボスHPは30〜90階でさらに1〜1.25倍。プレイヤーの現在能力を参照せず、強化して戻れば同じ階層の敵は楽になります。

固定狩りは従来のv83階層式のまま。RP強化・攻略の異変・狩り勝利数で敵のHP/攻撃は変化しません。敵・報酬の変更は次の戦闘からで、進行中の敵を弱くして報酬だけ高めることはできません。巨大箱ボスと前世対戦は別の決着処理で、攻略勝利・世界勝利・通常ドロップ・RP最高階層を増やしません。

### 固定条件での実戦比較

実ゲーム関数を使う比較ツールは21条件。通常装備の各所持数は固定の検証用構成で、入手過程や一般プレイヤーの進度は再現しません。乱数0.5固定、研究・読書・転生などの追加強化なし。RP強化Lvはエンジンと戦闘の両方を指します。

| 条件 | RP強化なし | RP強化あり |
| --- | --- | --- |
| Lv50・51階ボス・通常各10個・建物各10 | 8ターン勝利 | RP強化各Lv5：3ターン勝利 |
| Lv300・301階ボス・通常各100個・建物各100 | 87ターン勝利 | RP強化各Lv10：16ターン勝利 |
| Lv500・1000階・通常各100個・建物なし | 6ターンで敗北 | RP強化各Lv20：48ターン勝利 |

1000階の最後の条件は、上位装備の因果外の剣で17ターン、無窮至宝の剣で4ターン勝利。転生強化と希少装備の両方に使い道を残します。序盤の1階は従来どおり4ターン、装備各1個のLv25・26階ボスも従来どおり27ターンの比較結果です。

数分ごとの成長とボスの準備を狙う調整ですが、固定構成だけで実際の離脱率を断定しません。実機の長時間評価と、初回転生までの時間・RPの使い道・ボス再挑戦回数を公開後に確認する必要があります。

## 保存・安全性

`v85Rebirth.version=1` に独立して保存。旧所持金・ジェム・装備・秘蔵330種・研究・書庫・実績・世界進捗・過去のセーブフィールドは維持。旧セーブにはRP0・未購入を追加し、基本ツール4件のみ無料解放。既存建物をロード時にリセットしません。

従来の転生確認後に、今世の記録とRPを一度だけ確定してから、新しい世界へ設計図・出発セット・家宝を適用。キャンセル時は変更なし。直前バックアップは維持します。工房の追加自動化は初期OFFで、自動進行停止中・非表示・詳細画面・ボス報酬待ちには支出しません。新しい常駐タイマーは作らず既存時計を使います。

巨大箱ボスの参加費と未完了状態を保存し、途中再読み込み時は一致する参加費を一度返却。勝利時は返却予約を消して報酬と同時に保存し、決着ガードで二重報酬を防ぎます。挑戦中に転生した場合は通常の箱リセットとともに予約も消し、次のロードで返却を再生しません。敗北時は参加費を消費して予約を消します。通常のセーブ失敗通知と手動書き出し・復旧経路も引き継ぎます。
