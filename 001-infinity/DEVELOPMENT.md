# 001 ∞ 開発・回帰検証

`index.html` 単体で動作するゲームです。既存のチェックアウトで作業し、公開用 `main` へ直接 push しないでください。ビルドやデータ生成は不要です。

## 起動

```sh
cd /workspace/kontonkyo
python3 -m http.server 8081 --bind 127.0.0.1
```

別プロセスのブラウザーから `/001-infinity/` を開きます。ローカル検証に外部APIや認証情報は不要です。美術館の新しい作品取得など、既存の外部サービス連携は別途接続が必要です。

## 回帰検証

Node.js と Playwright、Chromium を使用します。クラウド環境では Playwright 1.56.1 をリポジトリ外へ導入しています。

```sh
cd /workspace/kontonkyo
NODE_PATH=/workspace/.setup/kontonkyo-browser/node_modules \
  node 001-infinity/tests/ux-auto.test.cjs
```

別環境では `require('playwright')` で読み込めるよう Playwright を用意し、必要なら `CHROMIUM_PATH` で Chromium 実行ファイルを指定してください。テストは一時的なHTTPサーバーと隔離されたブラウザー状態を使い、保存済みのユーザーデータや公開サイトへ接続しません。テスト専用の状態アクセスはサーバーの応答にだけ挿入され、本番ファイルには存在しません。画像などの出力先は `INFINITY_ARTIFACT_DIR` で指定できます。

## 既存の仕組みとAUTO

- 無窮の探索は実時間で箱を獲得する既存の放置探索です。戦闘は出撃すると既存のターン処理で決着まで進みます。XP、スキル、MP、複数の攻撃対象を選ぶシステムはありません。所持金・毎秒収入・✦通貨はプレイ領域の外の上部に常時表示します。レベル・調子・戦闘HP・階層と「強化まで」の表示はラベル付きに分けています。
- ゆめかわは戦闘のない、道と休息を選ぶ7歩の探索です。AUTOも同じ選択処理と元気の消費を利用し、踏破後は未発見の行き先を優先します。ゆめかわで自動戦闘だけを指定した場合は、探索を有効にする案内を表示して停止します。
- 探索・戦闘・ボス戦・追加報酬・シアターの設定は独立しています。初期状態では探索・戦闘・ボス戦・追加報酬・シアターはすべてON（保存済みの個別設定は維持）。設定は保存しますが、ページを開いただけではAUTOを再開しません。
- ×1/×2/×4 は操作と既存の戦闘ターンの間隔を変更します。放置収入、箱の時間当たり発見数、抽選確率、1回の行動の効果は変更しません。既存の「自動運転（−11%）」は別機能のままです。
- ボス戦AUTOがOFFなら出撃前に停止します。報酬自動選択がOFFなら追加報酬を待ちます。ONの場合は箱が2個未満なら箱、それ以外なら通貨を、既存の報酬処理で1回だけ選びます。
- AUTO停止・一時停止はAUTOが開始した戦闘も停止します。「手動に戻る」は既存の自動決着する戦闘処理へ引き継ぎます。手動介入、詳細画面、世界切替、非表示タブ、敗北ではAUTOを一時停止し、バックグラウンド中の戦闘ターンをまとめて実行しません。既存の放置報酬は維持します。 ゆめかわへ切り替えた間は、手動開始を含む無窮の戦闘を停止し、見えない場所で攻撃や報酬を進めません。
- シアター中も停止・速度・手動復帰を表示します。手動操作を開くとAUTOは一時停止します。背の低い画面ではプレイ領域の部分スクロールを許容します。

## セーブ互換性

主キー `observer-001-stable-v17` と既存の書き出し形式を維持します。コンポジションは装備品ではなく `mondrian` 着せ替えテーマです。所持を両世界共通の `shop.mondrian` に一度だけ付与し、新規の無窮のみ初期テーマにします。既存テーマ、装備ON/OFF、保存ビルド、世界別進捗は引き継ぎます。ゆめかわの初期テーマは変更しません。

移行前の生データは `observer-001-stable-v17-pre-v68` に保持します。 セーブ画面の「移行前のセーブを書き出す」から既存の読み込み形式で取り出せます（原本の保存キーは変更しません）。不正JSONの原本は修復用としてそのままダウンロードできます。バックアップを保存できない場合や元データの読み取りに問題がある場合は、自動保存による上書きを止め、警告と書き出し経路を表示します。保存失敗中の進行はメモリー上だけなので、ページを閉じる前にバックアップを確保してください。明示的なインポート・復旧・転生には既存の確認操作が残ります。

世界の入門目標と真の制覇条件、ダブルコンプリートのボーナス、現実モードの入口条件は元の計算を利用します。現実モードの内容は今回も実装しません。実機iPhone Safariの確認はChromiumのモバイル相当検証と区別してください。

## 表示の確認

主要な状態・操作は14px以上、所持金は32pxで表示します。小さい画面でも文字を縮めず、プレイ領域内でスクロールします。所持金と毎秒収入の既存ノードを使うため、収入・支出・表示形式の切替は元の処理のままです。シアターや手動復帰、プレイ領域のスクロールでも残高は隠れません。コンポジションのアクセント色と明るいテーマの背景色、無効ボタンの文字色を調整し、確認した主要操作のコントラスト比は4.5:1以上です。

## 箱の追加通貨

消費した箱1個ごとに装備とは独立して1/1000（0.1%）で✦1を抽選します。追加装備が複数出ても抽選は増えません。手動・まとめ開封・探索AUTO・既存の自動開封は同じ処理を通ります。確率は装備画面に明記し、通貨獲得時は上部に通知、手動・まとめ開封結果には合計を表示します。ボスや探索の従来報酬は変更しません。基本1箱/秒を全て開封する場合の期待値は✦3.6/時で、1000箱ごとの保証ではありません。

新規セーブから通常操作でAUTO開始→敗北→開封→2回強化→再開を試遊。今回の試遊では第6戦まで進み、実行時エラーはありませんでした。初期状態は戦闘で負けやすいため、敗北時の停止表示に装備集め・強化・再開の案内を追加しました。自動で強化費用を支払う処理や戦闘難易度の変更は行っていません。

表示修正版v73では、大きな戦闘HPは所持金の表示設定とは独立した短い指数表記にし、マウスオーバーで元の数値を確認できます。Lv178および最大HP1e308の状態で、表示の幅・所持金の可視性・HPバー50%・実際のHP値の保持を検証しました。詳細画面を閉じた後のAUTOは一時停止を維持し、再開方法が分かる状態文に更新します。
