# 001 ∞ 開発・回帰検証

`index.html` 単体で動作するゲームです。既存のチェックアウトで作業し、公開用 `main` へ直接 push しないでください。ビルドやデータ生成は不要です。

## 起動

```sh
cd /workspace/kontonkyo
python3 -m http.server 8081 --bind 127.0.0.1
```

別プロセスのブラウザーから `/001-infinity/` を開きます。ローカル検証に外部APIや認証情報は不要です。美術館の新しい作品取得など、既存の外部サービス連携は別途接続が必要です。

## 回帰検証

Node.js と Playwright、Chromium を使用します。クラウド環境では Playwright 1.56.1 をリポジトリ外へ導入しています。

```sh
cd /workspace/kontonkyo
NODE_PATH=/workspace/.setup/kontonkyo-browser/node_modules \
  node 001-infinity/tests/ux-auto.test.cjs
```

別環境では `require('playwright')` で読み込めるよう Playwright を用意し、必要なら `CHROMIUM_PATH` で Chromium 実行ファイルを指定してください。テストは一時的なHTTPサーバーと隔離されたブラウザー状態を使い、保存済みのユーザーデータや公開サイトへ接続しません。自動開始のライフサイクル検証は製品の既定状態をそのまま使用します。他の個別コントローラ検証は自動開始だけをテストブリッジで抑制し、意図した状態から操作します。テスト専用の状態アクセスはサーバーの応答にだけ挿入され、本番ファイルには存在しません。画像などの出力先は `INFINITY_ARTIFACT_DIR` で指定できます。

## 既存の仕組みとAUTO

- 無窮の探索は実時間で箱を獲得する既存の放置探索です。戦闘は出撃すると既存のターン処理で決着まで進みます。XP、スキル、MP、複数の攻撃対象を選ぶシステムはありません。所持金・毎秒収入・✦通貨はプレイ領域の外の上部に常時表示します。レベル・勝利数・戦闘HP・階層と「強化まで」の表示はラベル付きに分けています。
- ゆめかわは戦闘のない、道と休息を選ぶ7歩の探索です。AUTOも同じ選択処理と元気の消費を利用し、踏破後は未発見の行き先を優先します。世界を選ぶと自動で探索を始めます。旧休息の時間進捗は、ゆめかわ世界での滞在時間から加算し、既存の達成条件へ到達する経路を維持します。
- v75では「休む」と旧「自動運転」の操作、AUTO設定タブを廃止しました。探索・戦闘・ボス・追加報酬・シアターは常時有効。旧セーブの個別OFF設定も新しい標準に移行し、選択済み世界では起動時も自動進行します。初回は世界選択・チュートリアルが閉じるまで待機します。
- v76では「稼ぐ」ボタンと調子システムも廃止。旧セーブの `h` は変更せず保管しますが、収入・戦闘力・イベント・AUTO停止には使いません。収入は旧稼ぐモードの調子100%相当を基準にし、休息による減額はありません。封印・反転のボスへの守勢対応、戦闘HPの回復は維持します。ゆめかわ探索の元気は独立した既存の道選択ルールとして維持します。
- ×1/×2/×4 は操作と既存の戦闘ターンの間隔を変更します。放置収入、箱の時間当たり発見数、抽選確率、1回の行動の効果は変更しません。ボスの追加報酬は箱が2個未満なら箱、それ以外なら通貨を、既存の報酬処理で1回だけ選びます。
- 「進行停止」「一時停止」「手動に戻る」は明示的な停止として保存し、再読み込みでも維持します。敗北や進行異常も自動再試行しません。詳細画面・世界切替・非表示は一時的な停止で、閉じる／戻ると既存の500msループで再開します。非表示中の戦闘ターンはまとめて実行しません。ゆめかわの背後で無窮の戦闘を進めません。転生・インポート・復旧の介入では停止を維持します。
- シアター中も停止・速度・手動復帰を表示します。手動操作を開くとAUTOは一時停止します。背の低い画面ではプレイ領域の部分スクロールを許容します。

## セーブ互換性

主キー `observer-001-stable-v17` と既存の書き出し形式を維持します。コンポジションは装備品ではなく `mondrian` 着せ替えテーマです。所持を両世界共通の `shop.mondrian` に一度だけ付与し、新規の無窮のみ初期テーマにします。既存テーマ、装備ON/OFF、保存ビルド、世界別進捗は引き継ぎます。ゆめかわの初期テーマは変更しません。

移行前の生データは `observer-001-stable-v17-pre-v68` に保持します。 セーブ画面の「移行前のセーブを書き出す」から既存の読み込み形式で取り出せます（原本の保存キーは変更しません）。不正JSONの原本は修復用としてそのままダウンロードできます。バックアップを保存できない場合や元データの読み取りに問題がある場合は、自動保存による上書きを止め、警告と書き出し経路を表示します。保存失敗中の進行はメモリー上だけなので、ページを閉じる前にバックアップを確保してください。明示的なインポート・復旧・転生には既存の確認操作が残ります。

世界の入門目標と真の制覇条件、ダブルコンプリートのボーナス、現実モードの入口条件は元の計算を利用します。現実モードの内容は今回も実装しません。実機iPhone Safariの確認はChromiumのモバイル相当検証と区別してください。

## 表示の確認

主要な状態・操作は14px以上、所持金は32pxで表示します。小さい画面でも文字を縮めず、プレイ領域内でスクロールします。所持金と毎秒収入の既存ノードを使うため、収入・支出・表示形式の切替は元の処理のままです。シアターや手動復帰、プレイ領域のスクロールでも残高は隠れません。コンポジションのアクセント色と明るいテーマの背景色、無効ボタンの文字色を調整し、確認した主要操作のコントラスト比は4.5:1以上です。

## 箱の追加通貨

消費した箱1個ごとに装備とは独立して1/1000（0.1%）で✦1を抽選します。追加装備が複数出ても抽選は増えません。手動・まとめ開封・探索AUTO・既存の自動開封は同じ処理を通ります。確率は装備画面に明記し、通貨獲得時は上部に通知、手動・まとめ開封結果には合計を表示します。ボスや探索の従来報酬は変更しません。基本1箱/秒を全て開封する場合の期待値は✦3.6/時で、1000箱ごとの保証ではありません。

成長調整v74では、新規Lv1の初戦勝利を実際のターン処理で確認しています。開封・強化・AUTOを行う2分相当の操作再現ではLv24・17勝まで進行しました。強化を勝手に購入するAUTO処理は追加していません。成長計算と変更前後の比較は [BALANCE.md](BALANCE.md) を参照してください。

表示修正版v73では、大きな戦闘HPは所持金の表示設定とは独立した短い指数表記にし、マウスオーバーで元の数値を確認できます。Lv178および最大HP1e308の状態で、表示の幅・所持金の可視性・HPバー50%・実際のHP値の保持を検証しました。v75では詳細画面を閉じた後に自動進行を再開します。ただし明示的な停止は維持します。

## 建物 v76

画面下の「🏘 建物」から購入・強化できます。建物画面にも現在の所持金・毎秒収入を表示し、次のレベルの効果と費用を比較できます。「稼ぐ」ボタンの代わりに所持金の使い道として追加し、レベル強化も残します。自動購入はしません。

| 建物 | 初回価格 | Lv L の効果 | Lv25上限 |
| --- | ---: | --- | --- |
| 商店街 | 120 | 所持金生産＋8√L % | ＋40% |
| 箱の工房 | 600 | 箱＋0.05√L 個/秒 | ＋0.25個/秒 |
| 古紙回収所 | 360 | 空き箱＋√L 個/分 | ＋5個/分 |
| 紙片印刷所 | 1,800 | 紙片＋0.5√L 枚/分 | ＋2.5枚/分 |

各購入価格は初回価格×2^現在Lv、25レベルで停止。建物同士の倍率は掛け合わせません。商店街は収入にだけ補正し、直接の戦闘力補正はありません。工房の箱は既存の抽選・開封処理を使います。空き箱は既存の古紙回収操作を通して紙片へ交換します。回収所・印刷所は材料を消費しない独立した時間生産です。✦通貨を直接生む建物はありません。

`v76Buildings.version=1` にレベル・紙片と空き箱の端数を保存し、箱の端数は既存の `expeditionFraction` に合流します。旧セーブは全Lv0から始まり、所持金や装備は没収しません。両世界で共有し、輪廻でも保持。非表示中は従来の放置報酬計算を利用し、24時間上限と時間減衰を通して一度だけ付与します。AUTO速度で生産は増えません。

調子に関係していた通常装備の回復効果は戦闘HP回復に使用し、消耗軽減効果は被ダメージ軽減（最大25%）に変更しました。調子消耗という代償の表記は廃止。回復イベントは30秒分の拾得金、調子を下げていたイベントは空き箱1個の回収に置換しています。

## 探検・戦闘の拡張 v77

✦通貨の表示名は「ジェム」に統一しました。保存キーは従来の `coins` のまま、残高を換算せず使用します。価格・ボス報酬・箱の抽選率はこの名称変更では変えません。

夢の探検は既存の11景色・7歩・3択と元気のルールを維持し、景色ごとに3種類、全33の出来事を追加。旅の種と歩数から出来事を決めるので、再読み込みでも同じ場面になります。場所に合う道の追加効果を選択前に表示し、行動後は元気・きらめきの変化を文章で確認できます。追加のきらめきは1旅合計＋2まで、雨宿りの追加元気＋1は1旅1回。回復で元気10を超えることはありません。踏破報酬は元のきらめき計算を使います。

出会った場面と選んだ道は `dualWorld.v77.album` に保存。探検内の「旅の記録」か「すべて」から記録帳へアクセスできます。収集数は33件までで、既存の実績・世界制覇・現実モードの条件には追加していません。途中の旧セーブもそのまま続行可能。開始済みの探検を再開始する処理、無効な選択、終了済みの探検の再報酬をガードしています。

通常敵は階層に応じて3系統で、次の行動と威力を表示します。3ターンの威力は番人0.75/0.75/1.5、斥候1.25/0.75/1、夢喰い1/1.25/0.75。各平均は1で、基礎HP・基礎攻撃・階層曲線・出現確率は維持。ボスの回復阻害・装備封印・陰陽反転と、メタルの仕組みは維持します。

戦い方は攻撃（攻撃×1・被ダメ×1）、守り（攻撃×0.75・被ダメ×0.65）、集中（攻撃×1.25・被ダメ×1.2）。交戦中も変更でき、その戦闘中の指定を保持します。戦い方を選んでいる間はAUTOを停止し、選択またはフォーカスを外すと再開します。次の戦闘は「おまかせ」。AUTOは仕留められる時は集中、HPが35%未満か強攻撃が現在HPの30%以上になる時は守り、それ以外は攻撃を選びます。手動の指定を優先し、独自の能力値や抽選ボーナスは与えません。元の1秒ターンと速度制御で処理し、通常の報酬処理へ進みます。

追加の回帰検証は、ジェム残高の互換性、全33場面、場所と選択の効果上限、旅の種・記録の保存、二重踏破報酬の防止、実行動と予告の一致、3つの戦い方の被ダメージと攻撃、AUTO判断・手動優先・320px幅での操作を含みます。

AUTOシアターでは稼ぎの詳細欄を非表示にし、固定の所持金・ジェム表示を残して探検・戦闘の表示領域を優先します。手動復帰すると詳細へ再びアクセスできます。
