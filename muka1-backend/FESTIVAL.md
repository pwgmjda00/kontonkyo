# MUKA-1 定期興行仕様（Codex引き継ぎ）
日本時間を基準に開催。実票のみ使用。既存日次・週次集計との互換性を保つ。
- 日次: 8構文の大会、既存方式。
- 週次: 月曜〜日曜の日次大会票を合算。最多得票構文を王者とする。同票は共同王者、0票なら王者なし。
- 月次: その月に終了した週の王者を重複排除して候補にする。月末確定後、翌月1〜3日に独立した投票を開催。候補不足なら延期または不成立。共同王者も候補とする。
- 年間: その年の月間王者を重複排除して候補にする。12月分確定後、翌年1月4〜10日に年間決戦。候補数は最大12とは限らない（同票あり）。年間決戦の投票は月間・週次・日次と独立。
- 各特別大会は候補一覧から一つ選ぶ方式。端末単位の重複防止。過去大会は閲覧専用。候補確定後は変更しない。
- 集計確定処理は冪等、D1に期間・候補・結果を保存。遅延実行でも確定できること。既存票を破壊しない。過去12週制限をページングに変更し、殿堂を長期保存。
- 共有文例: 「今週いちばん腹立つ文章が決まりました」「この12月の王者、納得いかん」「今年の最悪を決めよう」。実在人物を対象にしない。
- トップに開催中の特別大会を一件だけ表示。通常の5秒決闘を妨げない。参加強制、連続ログイン報酬、架空票なし。
- 検証: JST境界、月跨ぎ週、年跨ぎ、同票、0票、候補重複、再実行、通信失敗、旧URL、投票期間外。
